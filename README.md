# mero-backend

> Memory + Road = 여행길을 기록하는 여행 일기
> 
여행 중 사용할 모바일 앱의 백엔드 API 서버입니다.

## 주요 기능
- 📝 여행 일기 작성 및 GPS 위치 기록
- 💰 다중 통화 경비 관리 (환율 자동 환산)
- 📸 사진 업로드
- 🔄 오프라인 우선 동기화 (SQLite ↔ PostgreSQL)

## 기술 스택

**Backend**
- Java 17, Spring Boot 3.5
- JPA / Hibernate
- Spring Security + JWT

**Database**
- PostgreSQL

**Infrastructure**
- Railway
- Supabase Storage
